# Memory Game

A browser-based Memory Game where the player finds matching pairs of cards.

## Description

The game contains 16 cards representing 8 pairs.

The player opens two cards at a time and tries to find all matching pairs
using the minimum number of moves.

## Features

- 16 cards / 8 pairs
- Random card shuffling
- Move counter
- Pair counter
- Victory modal
- New Game button
- Leaderboard
- Results saved in localStorage
- Responsive design
